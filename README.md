# 출퇴근 앱 (한양기술공업 출퇴근관리)

- 출근 / 퇴근 큰 버튼 + 찍힌 시간 표시
- 최초 1회 ID/비밀번호 저장 → 이후 자동 로그인 (암호화 저장)
- 회사 위치 등록 후 GPS 반경 진입 시 자동 출근, 이탈 시 자동 퇴근(설정한 시각 이후)

## APK 만들기

### 방법 A: Android Studio (PC)
1. Android Studio 설치 → `Open` 으로 이 폴더(`commute-app`) 열기
2. 처음 한 번 Gradle 동기화가 끝날 때까지 대기
3. 메뉴 `Build > Build Bundle(s) / APK(s) > Build APK(s)`
4. `app/build/outputs/apk/debug/app-debug.apk` 를 폰으로 옮겨 설치 (설치 시 "출처를 알 수 없는 앱" 허용 필요)

### 방법 B: GitHub Actions (PC에 아무것도 설치 안 함)
1. 이 폴더를 새 GitHub 저장소(비공개 권장)에 올리기
2. 저장소의 `Actions > Build APK > Run workflow`
3. 끝나면 결과의 `commute-apk` 아티팩트에서 APK 다운로드

## 처음 사용 순서
1. 앱 실행 → 설정에 아이디/비밀번호 입력 → 저장
2. 바로 찍지 말고, 먼저 `설정 > 사이트 직접 열기`로 사이트가 정상적으로 열리는지 확인
3. 회사에서 `지금 위치를 회사로 등록` → `회사 도착/이탈 시 자동 출퇴근` 켜기
   - 위치 권한은 반드시 `항상 허용`
4. 정확한 시각의 알림을 위해 `알람 및 리마인더` 허용 (앱이 처음 안내함)
5. 폰 설정 > 앱 > 출퇴근 > 배터리 > `제한 없음`(최적화 제외)으로 설정해야 자동 인식이 안정적입니다

## 동작 규칙
- **출근/퇴근 버튼은 앱이 열려 있는 동안 폰 GPS로 회사까지 거리를 계속 확인하다가, 허용 반경(기본 50m) 이내일 때만 활성화됩니다.** 버튼을 누르는 순간에도 위치를 한 번 더 확인합니다.
- GPS 오차가 100m보다 크거나, 모의(가짜) 위치가 켜져 있으면 버튼이 켜지지 않습니다. 회사 사이트도 폰의 GPS 위치로 판단합니다.
- 알림: 출근 10분 전(07:50), 퇴근 시각(17:00)에 "찍어야 해요" 알림. 이미 찍었으면(사이트 기록 확인 포함) 알림이 오지 않습니다. 주말 제외 옵션 적용.
- 자동 출근: 회사 근처(약 100m)에 들어오면 앱이 깨어나 30초마다 최대 10분간 위치를 확인하고, 50m 이내가 되면 하루 1회 출근을 찍습니다.
- (선택) '회사를 벗어날 때 자동 퇴근'을 켜면 이탈 시 설정 시각 이후 자동 퇴근. 벗어난 뒤라 50m 규칙은 적용되지 않습니다.
- 화면 맨 위에 회사 사이트 로그인 상태(🟢/🔴)가 표시됩니다.
- 이미 처리된 날은 다시 찍지 않음 (수동 버튼은 확인창 후 다시 찍기 가능)

## 알아둘 점
- GPS는 실내에서 오차가 20~50m 나기도 해서, 50m 안인데도 거절될 수 있습니다. 그럴 땐 창가/입구에서 다시 누르거나 설정에서 허용 반경을 늘리세요.
- 사이트 화면 구조가 바뀌면(버튼 함수명 `ExecCommuteClick`, 시간 입력칸 id 등) 동작하지 않을 수 있습니다.

## 로고 넣기 (선택)
로고는 `app/src/main/res/drawable-nodpi/company_logo.png`에 들어 있습니다(흰 바탕 버전). 파일을 바꾸고 다시 빌드하면 교체됩니다. 파일이 없으면 "한양기술공업" 글자로 표시됩니다.

## 모의 실행 (실제로 찍지 않는 점검)
설정 > 점검 > `출근 모의 실행` / `퇴근 모의 실행`: 로그인, 출퇴근 화면, 버튼 존재, 위치 확인까지만 하고 출퇴근 기록은 남기지 않습니다. 결과는 화면 아래 메시지와 알림으로 나옵니다.

## 회사 위치 표시 (v1.2)
- 위치명(예: AF(드림시티))은 사이트에서 자동으로 읽어옵니다. (사이트에는 주소·좌표가 직원 화면에 없습니다)
- 설정에서 회사 위치를 등록하는 방법은 두 가지입니다.
  1. 회사 안에서 `지금 위치를 회사로 등록` → 주소가 자동으로 찾아져 화면에 `주소 - 위치명`으로 표시
  2. `회사 주소`를 입력하고 `주소로 회사 위치 찾기` → 폰의 주소 검색으로 좌표 변환
- 등록한 위치 50m 이내에 들어오면 위치 카드에 `주소 - 위치명`과 함께 출근/퇴근 버튼이 켜집니다.

## v1.3 — 출근지 자동 인식
- 출근지 판단은 회사 사이트가 폰 GPS로 합니다. 지정된 출근지 근처에 가면 사이트가 출근지명을 채워 주고, 앱은 그 이름을 표시하며 출근/퇴근 버튼을 켭니다.
- 앱을 열어 둔 동안 1분마다 확인합니다 (최대 40초 소요).
- 사이트가 근처로 인정한 순간의 좌표를 출근지명과 함께 기억해, 이후 자동 출근(지오펜스)에 사용합니다. 처음 한 번은 출근지에서 앱을 열어야 합니다.
- 수동 출근지 등록은 선택 사항입니다.

## v1.5 — 자동 빌드 · 앱 내 업데이트
- GitHub 에 push 하면 Actions 가 서명된 APK 를 만들어 Releases 에 올립니다 (`HanyangCommute-vX.Y.apk`).
- 앱은 설정 탭의 "업데이트 저장소"(아이디/저장소)를 보고, 열 때(6시간에 한 번) 새 버전을 찾아 설치 화면까지 띄웁니다. 저장소는 Public 이어야 합니다.
- 고정 서명키(app/release.jks)를 사용하므로 이후 버전은 기존 앱 위에 덮어 설치됩니다.
- 새 버전 올릴 때는 app/build.gradle.kts 의 versionCode/versionName 을 올려야 합니다.
